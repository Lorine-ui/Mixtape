# Mixtape 1.2 (C++)

Музыкальный плеер для Windows одним `.exe`: поиск по названию сразу в Audius, SoundCloud, Internet Archive и YouTube,
без рекламы, чёрная тема в духе Spotify, виниловая вертушка, текст песен в такт музыке, фрагменты («оставить» / «вырезать»),
перенос плейлистов по ссылке без ключей, офлайн-режим, кнопка «Случайная песня», работа в свёрнутом окне.
Нажмите на имя исполнителя (в списке, в мини-проигрывателе, на экране проигрывателя, в статистике): откроются все его песни и
альбомы с YouTube Music, альбом открывается нажатием на обложку. Если такого исполнителя там нет, покажется обычный поиск.

## Сборка (Windows 10/11, Visual Studio 2022 или Build Tools, CMake 3.21+)

    cmake -S . -B build -G "Visual Studio 17 2022" -A x64
    cmake --build build --config Release

Готовый файл: `build/Release/Mixtape.exe` (CRT статическая, внешние DLL не нужны).
При первой настройке CMake скачивает Dear ImGui 1.91.5, miniaudio 0.11.21 и stb (нужен интернет).

### yt-dlp (по желанию)

YouTube отдаёт песню целиком только через [yt-dlp](https://github.com/yt-dlp/yt-dlp). Если положить `yt-dlp.exe` в `resources/`
перед сборкой, он вшивается в `Mixtape.exe` и сам распаковывается в `%APPDATA%\Mixtape` при первой песне из YouTube Music.
Без этого файла приложение собирается как обычно и ищет `yt-dlp.exe` рядом с `Mixtape.exe` или в PATH, а если его нет, играет ту же
песню из других источников. Сам `yt-dlp.exe` в репозиторий не входит (лицензия yt-dlp — Unlicense).

## Друзья и рекомендации (без сервера)

«Друзья» в боковой панели. Сервера у Mixtape нет, поэтому всё идёт ссылками, которые вы отправляете друг другу в любой мессенджер:

* **Приглашение.** «Скопировать ссылку» даёт вашу ссылку-приглашение. Друг вставляет её в поле «Вставьте ссылку от друга» (или прямо в строку поиска),
  и вы появляетесь в его списке с вашим ником, цветом и рамкой. Чтобы вы увидели его, он отправляет вам свою ссылку.
* **Рекомендация.** «+» у песни → «Порекомендовать другу» (или «Отправить песню» на странице друзей) копирует ссылку на песню.
  Друг вставляет её, и песня появляется у него в разделе «Вам рекомендуют»: послушать, добавить в «Мою музыку» или скрыть.

Ссылка выглядит как `https://github.com/Lorine-ui/Mixtape#mx-…`: по ней можно перейти на страницу Mixtape, а вся информация лежит в «хвосте» после `#`
и никуда не отправляется. Рамок для аватарки 12 (Профиль → Рамка аватарки). Профиль (ник, фото, цвет, рамка) и список друзей хранятся
только на устройстве (`profile.json`, `friends.json`). Входа в аккаунт и синхронизации через интернет больше нет; переносить музыку между
устройствами можно резервной копией (Настройки → Данные).

## Перенос из старой версии

Настройки → Данные → «Перенос из старой версии»: Mixtape сам находит библиотеки прежних версий (рядом с `.exe`, в `%LOCALAPPDATA%`,
в папках `Mixtape…` среди данных программ) и переносит «Мою музыку», плейлисты, свои файлы и скачанные копии. То, что уже есть, не
дублируется. Если библиотека пуста и найдена старая, при запуске появится подсказка. Кнопка «Выбрать файл library.json» берёт
любую папку или копию вручную.

## Устройство

| Папка | Что внутри |
|---|---|
| `core/` | Платформонезависимое ядро: JSON, модель, библиотека, очередь, вырезы, ранжирование, микшер |
| `app/net/` | Источники и поиск (`net.cpp`), WinHTTP (`http_winhttp.cpp`) за интерфейсом `IHttp` |
| `app/audio/` | miniaudio + микшер, декодер Media Foundation для AAC/m4a |
| `app/app.cpp` | Логика приложения без рисования |
| `app/ui/` | Dear ImGui: каркас, списки, проигрыватель, окна |
| `app/main_win32.cpp` | Окно, DirectX 11, диалоги, медиаклавиши, перетаскивание файлов |
| `resources/` | Иконка и картинка Тето (вшиваются в exe) |
| `tests/` | Тесты ядра, сети (с подменой HTTP) и микшера |

Тесты запускаются на любой ОС: `cmake -S . -B b -DMX_BUILD_APP=OFF && cmake --build b && ctest --test-dir b`.

## Discord: «Слушает Mixtape»

Пока песня играет, Mixtape может показывать в профиле Discord название, исполнителя, обложку и минуту (как у Spotify).
Работает только на компьютере и только если запущено приложение Discord. На паузе статус убирается.

1. Откройте <https://discord.com/developers/applications>, создайте приложение с названием **Mixtape** (его увидят в статусе)
   и скопируйте **Application ID** со страницы General Information.
2. Вставьте его в `app/discord_config.hpp` (`kDiscordAppId`) и пересоберите. Пока ID пустой, ничего не отправляется.
3. В Mixtape появится переключатель «Настройки → Воспроизведение → Показывать в Discord».

В Discord должно быть включено «Настройки пользователя → Приватность активности → Показывать мою активность».
Под статусом показывается кнопка со ссылкой (`kDiscordButtonLabel`, `kDiscordButtonUrl`); чтобы убрать её, очистите адрес.

## Данные

`%APPDATA%\Mixtape\`: `library.json` (формат совместим с резервной копией старого приложения), `offline\`, `files\`.
Свою анимацию Тето можно положить как `ui_teto.gif` в эту папку.
Свой фон (картинка или GIF) выбирается в «Настройки → Оформление → Свой фон» и хранится здесь же как `ui_bg.*`.
Крупные картинки и длинные GIF при загрузке уменьшаются, чтобы не занимать много памяти (до 400 кадров, файл до 40 МБ).

## Ограничения

* YouTube Music: песня целиком играет только с yt-dlp (вшитым или лежащим рядом); без него или если он не справился, она ищется в других источниках.
* Скорость меняет и тон (как у пластинки).
* Масштаб интерфейса при высоком DPI делает Windows (картинка может быть чуть мягче).
