# Mixtape для Android

Отдельная версия для телефона. Версия для компьютера живёт в папке `mixtape-cpp` и отсюда не меняется.

## Установить на телефон

1. Скопируйте `Mixtape.apk` на телефон (кабель, Telegram, облако — как удобно).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника — разрешите.
3. При первом запуске Mixtape попросит разрешение на уведомления: оно нужно, чтобы музыка играла
   с выключенным экраном и в шторке были кнопки «назад / пауза / вперёд».

Нужен Android 10 или новее.

## Что умеет телефонная версия

* Поиск сразу в Audius, SoundCloud, Internet Archive и YouTube Music, «Моя музыка», плейлисты, фрагменты, тексты песен.
* Скачивание для офлайна (вкладка «Офлайн»), «Сохранить на компьютер» кладёт файл в «Музыка/Mixtape».
* Вкладки снизу: Главная, Моя музыка, Офлайн, Ещё (фрагменты, плейлисты, перенос, файлы, настройки).
* Списки листаются пальцем, текст вводится обычной клавиатурой телефона.
* Кнопка «Назад» закрывает окна, а на главном экране сворачивает приложение — музыка играет дальше.
* Резервная копия сохраняется в «Загрузки/Mixtape».
* Подходит для разных экранов: узкие телефоны, горизонтальный режим (вкладки и проигрыватель перестраиваются), планшеты.

Данные телефона отдельные: библиотеку с компьютера можно перенести через резервную копию
(на компьютере «Настройки → Данные → Сохранить копию», на телефоне «Загрузить копию»).

## YouTube Music и yt-dlp

YouTube отдаёт песню целиком только через [yt-dlp](https://github.com/yt-dlp/yt-dlp). В APK вшита библиотека
[youtubedl-android](https://github.com/yausername/youtubedl-android) (Python, yt-dlp и движок QuickJS), поэтому APK весит около 40 МБ.
Первая песня из YouTube Music грузится дольше обычного: распаковывается Python и, если вшитый yt-dlp старше 45 дней, он обновляется с
официальной страницы выпусков yt-dlp на GitHub (не чаще раза в 6 часов). Если yt-dlp не справился, песня играет из других источников,
а причина отказа показывается в сообщении.

**Лицензия.** youtubedl-android распространяется по [GPL-3.0](https://www.gnu.org/licenses/gpl-3.0.html), поэтому APK целиком
выпускается на условиях GPL-3.0 (текст — в файле `LICENSE-GPL-3.0.txt`); исходный код всего приложения открыт и лежит в этом репозитории.
Собственный код Mixtape по-прежнему доступен по лицензии MIT, см. `LICENSE` в корне репозитория.

## Собрать APK заново

Запустите `android\build_apk.bat`. Нужны инструменты в `%USERPROFILE%\Android`
(JDK 17, Android SDK 34, NDK 26.3, CMake 3.22, Gradle 8.7) — они уже установлены.
Готовый файл появится как `android\Mixtape.apk`.

## Устройство

| Папка | Что внутри |
|---|---|
| `core/`, `app/` | Тот же код, что у версии для компьютера, плюс телефонный режим (`app/ui/mobile.cpp`) |
| `android/app/src/main/cpp/` | Окно на OpenGL ES, сенсорный ввод, HTTP через Java, декодер m4a через MediaCodec |
| `android/app/src/main/java/` | Окна Android: ввод текста, выбор файлов, сохранение в «Музыку», фоновая игра |
