# Mixtape 1.2 (C++)

Музыкальный плеер для Windows одним `.exe`: поиск по названию сразу в Audius, SoundCloud, Internet Archive и YouTube,
без рекламы, чёрная тема в духе Spotify, виниловая вертушка, текст песен в такт музыке, фрагменты («оставить» / «вырезать»),
перенос плейлистов по ссылке без ключей, офлайн-режим, кнопка «Случайная песня», работа в свёрнутом окне.

## Сборка (Windows 10/11, Visual Studio 2022 или Build Tools, CMake 3.21+)

    cmake -S . -B build -G "Visual Studio 17 2022" -A x64
    cmake --build build --config Release

Готовый файл: `build/Release/Mixtape.exe` (CRT статическая, внешние DLL не нужны).
При первой настройке CMake скачивает Dear ImGui 1.91.5, miniaudio 0.11.21 и stb (нужен интернет).

## Устройство

| Папка | Что внутри |
|---|---|
| `core/` | Платформонезависимое ядро: JSON, модель, библиотека, очередь, вырезы, ранжирование, микшер |
| `app/net/` | Источники и поиск (`net.cpp`), WinHTTP (`http_winhttp.cpp`) за интерфейсом `IHttp` |
| `app/audio/` | miniaudio + микшер, декодер Media Foundation для AAC/m4a |
| `app/app.cpp` | Логика приложения без рисования |
| `app/ui/` | Dear ImGui: каркас, списки, проигрыватель, окна |
| `app/main_win32.cpp` | Окно, DirectX 11, диалоги, медиаклавиши, перетаскивание файлов |
| `resources/` | Иконка и картинка Тето (вшиваются в exe) |
| `tests/` | Тесты ядра, сети (с подменой HTTP) и микшера |

Тесты запускаются на любой ОС: `cmake -S . -B b -DMX_BUILD_APP=OFF && cmake --build b && ctest --test-dir b`.

## Данные

`%APPDATA%\Mixtape\`: `library.json` (формат совместим с резервной копией старого приложения), `offline\`, `files\`.
Свою анимацию Тето можно положить как `ui_teto.gif` в эту папку.

## Ограничения

* YouTube: прямые потоки отдаются не всегда; тогда песня ищется в других источниках.
* Скорость меняет и тон (как у пластинки).
* Масштаб интерфейса при высоком DPI делает Windows (картинка может быть чуть мягче).
